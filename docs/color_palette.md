# Paytm — Color Palette

## 1. Overview

Paytm's visual identity is built around a distinctive combination of bright cyan blue and deep navy blue.

The interface complements these brand colors with white surfaces, soft blue backgrounds, neutral typography, and subtle status colors.

**Visual direction:** Modern, trustworthy, clean, energetic, accessible.

## 6. Color Hierarchy

Recommended usage hierarchy:

1. **Paytm Cyan:** Primary brand identity and important interactive highlights.
2. **Paytm Navy:** Strong typography, navigation and primary dark elements.
3. **White:** Main content surfaces and cards.
4. **Soft Blues:** Background sections, informational panels and subtle visual separation.
5. **Neutrals:** Typography, borders and supporting interface elements.
6. **Semantic Colors:** Status indicators and operational feedback.

## 7. Application Guidelines

### Buttons
- Primary button: Paytm Navy or Paytm Cyan, depending on context.
- Secondary button: White with Paytm Navy border.
- Hover states: Slightly darker or deeper shade of the original color.

### Cards
- Prefer white surfaces.
- Use subtle borders and soft shadows.
- Use pale blue backgrounds for highlighted promotional or informational sections.

### Typography
- Use dark navy or deep slate for primary text.
- Use muted slate for secondary information.
- Use Paytm Cyan selectively for emphasis.

### Backgrounds
- Keep the primary page background light.
- Use white cards for content separation.
- Avoid excessive saturated blue backgrounds.

### Status Indicators
- Green for successful operations.
- Amber for pending or attention-required operations.
- Red for failures.
- Blue for informational states.
